# Real_estates

재개발·재건축 프로젝트별 웹페이지 소스 저장소.

## 구조

```
godeok1/     고덕1구역 재개발 (운영 중)
muak/        무악현대아파트 재건축 (준비 중)
```

프로젝트마다 폴더를 하나씩 쓰고, **Netlify 사이트도 프로젝트마다 하나씩** 둡니다.
한 저장소에서 여러 사이트를 띄울 수 있습니다 — Netlify의 **Publish directory**만 각각 다르게 지정하면 됩니다.

| 폴더 | Netlify Publish directory | 상태 |
|---|---|---|
| `godeok1` | `godeok1` | 운영 중 |
| `muak` | `muak` | 미개설 |

새 프로젝트를 추가할 때는 폴더를 만들고, Netlify에서 **Add new site → Import from Git**으로 같은 저장소를 고른 뒤 Publish directory만 그 폴더 이름으로 넣으면 됩니다.

> **운용 매뉴얼은 [](OPERATIONS.md)에 있습니다.** 구축 경위, Netlify 설정값, 문제 해결, 새 프로젝트 추가 방법까지 정리되어 있습니다.

## 수정 방법

1. 위 파일 목록에서 폴더(`godeok1`) → `index.html` 클릭
2. 오른쪽 위 연필 아이콘(✏️ Edit this file) 클릭
3. 고칠 내용 찾아서 수정 — `Ctrl+F`로 숫자 검색하면 빠릅니다
4. 아래로 내려서 **Commit changes** 클릭
5. 30초~1분 뒤 사이트에 반영

Netlify 재배포는 자동입니다. 따로 할 일 없습니다.
