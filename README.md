# 고덕1구역 재개발 홍보 페이지

Netlify에 연결된 소스입니다. **이 저장소의 파일을 고치면 사이트가 자동으로 바뀝니다.**

## 수정 방법

1. 위 파일 목록에서 `index.html` 클릭
2. 오른쪽 위 연필 아이콘(✏️ Edit this file) 클릭
3. 고칠 내용 찾아서 수정 — `Ctrl+F`로 숫자 검색하면 빠릅니다
4. 아래로 내려서 **Commit changes** 버튼 클릭
5. 30초~1분 뒤 사이트에 반영

Netlify 재배포는 자동입니다. 따로 할 일 없습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 사이트 본문 (이것만 고치면 됩니다) |
| `godeok1-owners.html` | 동일 내용 사본 |
| `og-image.png` | 카카오톡·링크 공유 시 뜨는 썸네일 |

`index.html`과 `godeok1-owners.html`은 같은 내용입니다. 하나만 고치면 다른 쪽은 안 바뀌니, **두 주소를 다 쓰고 계시면 둘 다 고쳐야 합니다.**
